Getting Started

最短 1 ステップで AlphaForge を動かす

Trial プランは Whop 登録不要・期限なしで、インストール直後からそのまま使えます（所要時間 約 5 分）。有料プラン（Lifetime / Annual / Monthly）の機能解放のみ Whop OAuth 認証が必要です。詳細手順は公式ドキュメントへ。

詳しい手順・パラメータ・トラブルシューティング全集は 公式ドキュメントを参照してください。

ドキュメントを開く →

ステップ 1 — CLI をインストール

ターミナルで実行します。インストーラーが最新バイナリをダウンロードし、/usr/local/bin に配置します。

curl -sSL https://alforge-labs.github.io/install.sh | bash

PowerShell（管理者権限不要）で実行します。バイナリを %LOCALAPPDATA%\Programs\alpha-forge にインストールし、PATH を自動設定します。

irm https://alforge-labs.github.io/install.ps1 | iex

インストーラを使わず手動で配置したい場合は、 GitHub Releases（最新版） から各プラットフォーム向けバイナリを直接ダウンロードできます。

ステップ 2 — そのまま Trial プランで使う（Whop 登録不要）

インストール直後から Trial プランで alpha-forge backtest run / alpha-forge optimize run / alpha-forge optimize walk-forward 等が動きます。Trial の制限はデータ上限 2023-12-31・最適化 50 trials・Pine Script 生成不可の 3 点のみで、それ以外は有料プランと同じ機能を試せます。 

# 例: いきなりバックテストを動かす（Trial プラン・Whop 登録不要）
alpha-forge system init                 # 作業ディレクトリ初期化
alpha-forge data fetch SPY --period 5y  # 2023-12-31 までのデータを自動取得
alpha-forge backtest run SPY --strategy sma_crossover_v1

有料プラン（任意） — Whop でログイン認証

Trial の制限を解除したい場合のみ、Whop の有料プラン（Lifetime / Annual / Monthly）を購入してから以下を実行します。OAuth 2.0 PKCE 認証でブラウザが自動で開き、認証情報は ~/.config/forge/credentials.json に保存されます。 

alpha-forge system auth login

認証済みメンバーシップは以下で確認できます：

alpha-forge system auth status

Trial / 各有料プランの機能差は Trial 制限 を参照。

結果を可視化する — alpha-visualizer（任意）

alpha-visualizer は forge が出力するバックテスト結果を Web ブラウザで可視化する OSS パッケージです（PyPI 配布・Apache-2.0 ライセンス）。forge 本体に依存せず単体動作するため、必要に応じて後から追加できます。 

# uv（推奨）
uv tool install alpha-visualizer

# pip
pip install alpha-visualizer

詳しい使い方・設定は alpha-visualizer インストールガイド を参照してください。PyPI: pypi.org/project/alpha-visualizer / GitHub: alforge-labs/alpha-visualizer

自動発注ブリッジ — alpha-strike（任意）

alpha-strike は TradingView アラートを Webhook で受け取り、moomoo 証券（米国株 / 香港株 / 暗号資産）と OANDA 証券（FX / CFD）へ自動発注するセルフホスト型ブリッジです（PyPI 配布・Apache-2.0 ライセンス）。 Oracle Cloud Always Free + Cloudflare Tunnel + WAF のリファレンス構成で月額 0 円で本格運用できます。 

# uv（推奨）
uv tool install alpha-strike

# pipx でグローバル CLI として
pipx install alpha-strike

# pip
pip install alpha-strike

# 起動
WEBHOOK_PASSPHRASE=your-secret alpha-strike

VM プロビジョニング・Cloudflare Tunnel・WAF・systemd の完全手順は alpha-strike セットアップガイド を参照してください。PyPI: pypi.org/project/alpha-strike / GitHub: alforge-labs/alpha-strike
